# AI Agent 설계 문서

## 개요

AI 운동 코치 앱은 Claude API를 활용하여 사용자의 목표와 조건에 맞는 맞춤형 주간 운동 루틴을 생성합니다.

## 사용 모델

- **모델**: `claude-sonnet-4-20250514`
- **선택 이유**: 구조화된 JSON 출력과 전문적인 운동 지식을 동시에 활용하기 위해 Sonnet 선택. 운동 과학 도메인 지식이 충분하고 한국어 응답 품질이 우수함.

## 프롬프트 설계

### 시스템 프롬프트

```
당신은 전문 퍼스널 트레이너입니다.
사용자의 목표와 조건을 보고 다음 JSON 형식으로만 응답하세요:
{
  "routine_name": "루틴 이름",
  "days_per_week": 숫자,
  "weekly_plan": [
    {
      "day": "요일 (예: 월요일)",
      "focus": "운동 부위 또는 유형",
      "exercises": [
        {
          "name": "운동 이름",
          "sets": 숫자,
          "reps": "횟수 또는 시간",
          "description": "자세 설명 한 줄"
        }
      ]
    }
  ]
}
```

### 사용자 메시지

```
목표: {goalType}
주당 운동 횟수: {daysPerWeek}회
운동 장비: {hasEquipment ? "있음 (덤벨, 바벨, 기구)" : "없음 (맨몸 운동만)"}
```

### 설계 원칙

| 원칙 | 내용 |
|------|------|
| 전문가 페르소나 | "전문 퍼스널 트레이너" 역할로 신뢰성 있는 운동 처방 유도 |
| 구조화된 출력 | JSON 형식 강제로 파싱 안정성 확보 |
| 조건 기반 생성 | 장비 유무에 따라 완전히 다른 루틴 생성 (맨몸 vs 기구 운동) |
| 주간 계획 | 요일별 분할로 앱의 달력 연동이 가능하도록 설계 |

## API 요청 구조

```json
{
  "model": "claude-sonnet-4-20250514",
  "max_tokens": 2048,
  "system": "...(시스템 프롬프트)...",
  "messages": [
    { "role": "user", "content": "목표: 근력\n주당 3회\n장비: 있음" }
  ]
}
```

> `max_tokens: 2048` — 루틴은 5~6일치 운동을 포함하므로 1024보다 큰 토큰 예산 설정

## 응답 처리 (`claude_client.dart`)

1. Markdown 코드블록 제거 (` ```json ` 등)
2. JSON 직접 파싱 시도
3. 실패 시 정규식으로 `{...}` 블록 추출
4. 파싱 실패 시 예외 발생

## 생성 데이터 예시

```json
{
  "routine_name": "3일 분할 근력 루틴",
  "days_per_week": 3,
  "weekly_plan": [
    {
      "day": "월요일",
      "focus": "가슴/삼두",
      "exercises": [
        { "name": "벤치프레스", "sets": 4, "reps": "8-10회", "description": "바를 가슴에 내리고 팔꿈치를 45도 유지" },
        { "name": "딥스", "sets": 3, "reps": "10-12회", "description": "상체를 약간 앞으로 기울여 가슴 위주 자극" }
      ]
    }
  ]
}
```

## 보안
