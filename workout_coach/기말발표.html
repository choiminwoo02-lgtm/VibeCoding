01 — 비전 & 문제 정의

왜 만드는가

운동 루틴을 갖는 것이 왜 비용이나 전문 지식이 있어야만 가능한가. 이 질문에서 시작했습니다.

"누구나 자신에게
꼭 맞는 운동 루틴을
가질 수 있어야 한다."

퍼스널 트레이너를 고용할 여건이 없어도, 운동 지식이 부족해도 — 3가지 질문만으로 나만의 주간 루틴을 즉시 설계하고, 세트 단위로 기록하며 꾸준히 실천하도록 돕는다.

🎯
개인화
목표·장비·요일 3가지 조건으로 나만의 루틴 즉시 생성. 마음에 안 드는 종목은 미리보기에서 바꿀 수 있다.
📈
지속성
세트 수/횟수를 직접 조절하며 완료 체크. 월간 달력과 부위별 차트로 꾸준함을 시각화한다.
🔒
프라이버시
모든 데이터를 기기 내 SQLite(모바일) 또는 인메모리 DB(웹)에 저장. 외부 서버 불필요.
Pain 1
루틴 설계의 진입 장벽
운동 초보자는 무엇을, 몇 세트, 어떤 순서로 해야 할지 결정하기 어렵다. 잘못된 루틴은 부상이나 포기로 이어진다.
스마트 루틴 알고리즘 + 미리보기 편집으로 즉시 생성
Pain 2
일반 루틴의 낮은 개인화
유튜브·블로그의 범용 루틴은 장비 유무, 목표, 선호 요일을 반영하지 못한다.
7부위 42종목 + ↔ 종목 교체로 나만의 루틴 완성
Pain 3
PT 비용 장벽
월 30~50만 원 이상의 퍼스널 트레이닝은 대다수에게 부담이다.
로컬 스마트 알고리즘 + 직접 만들기로 무료 대체
Pain 4
지속성 추적의 부재
루틴을 메모·캡처로 관리하면 완료 기록, 달성률 확인이 어려워 동기가 끊긴다.
세트 단위 기록 + 월간 달력 + 부위별 바 차트

05 — 문제 해결

개발 중 해결한 것들

개발 과정에서 마주친 4가지 문제와 해결 방법입니다.

01
Windows 빌드 실패 — 한글 경로
C:\Users\민우\ 경로의 한글을 MSBuild가 인코딩 오류로 처리
Windows 네이티브 대신 Chrome 웹으로 전환 — flutter run -d chrome
02
Gemini API 할당량 초과 (429)
무료 API 키의 프로젝트 레벨 quota = 0, 처음부터 호출 불가
AI API 제거 → 로컬 랜덤 셔플 알고리즘으로 스마트 루틴 생성 대체
03
운동 이미지가 모두 같은 사진
Unsplash ID 매핑 오류 + ExerciseTile에 이미지 위젯 자체 누락
Pexels CDN으로 전환 · 42종목 Photo ID 개별 매핑 · 위젯 추가
04
_daysPerWeek 컴파일 에러
주 횟수를 숫자에서 요일 목록(_selectedDays)으로 변경 후 참조 누락
_daysPerWeek - 1 → _selectedDays.length - 1 로 전체 참조 수정
